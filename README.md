# 책표지 탐정단 — 사라진 이야기 열쇠

독서교육 박람회 부스용 체험 웹앱. 책 표지 퍼즐 → 틀린그림 찾기 → 메모리 게임을 한 사건의 단서 찾기로 묶고, 마지막에 오늘 만난 책을 다시 보여 준다. 초등학교 2~3학년 기준으로 설계했다.

## 실행 방법

1. Node.js(18 이상)가 설치되어 있어야 한다. (설치 확인: `node --version`)
2. 이 폴더에서 `start.cmd`를 더블클릭한다. 서버가 켜지고 브라우저가 `http://localhost:8080`으로 열린다.
   - 직접 실행하려면: `node serve.cjs 8080`
3. 창을 닫지 말고 운영한다. 종료는 서버 창에서 `Ctrl+C`.

빌드 과정, 외부 패키지, 인터넷 연결은 필요 없다. 최초 1회 자료를 불러온 뒤에는 같은 탭에서 인터넷이 끊겨도 체험을 계속할 수 있다.

> 파일을 더블클릭해 `file://` 로 여는 방식은 모듈·이미지 로딩이 막히므로 사용하지 않는다. 반드시 서버로 연다.

## 동작 개요

- 처음 열면 `assets/manifest.json`의 표지를 브라우저 저장소(IndexedDB)로 가져오고, 실제 표지 운영 구성으로 시작한다.
- 시작 화면에서 쉬운 모드(퍼즐 1·틀린그림 1·메모리 8장)와 어려운 모드(퍼즐 3권으로 마지막은 9조각·틀린그림 3·메모리 12장 × 2판)를 고른다. 모드별 도서 구성은 교사용 설정에서 바꾼다.
- 교사용 설정은 시작 화면 맨 아래 '교사용 설정' 링크(확인 창 통과) 또는 주소 `http://localhost:8080/#admin` 으로 연다.
- 게임 화면 오른쪽 위 `⌂` 버튼은 운영자용 '처음으로'이며 확인 창을 거친다.
- 학생 진행 상태는 세션에만 있어 새로고침하면 시작 화면으로 돌아간다. 등록 자료와 설정은 유지된다.
- 소리는 기본 꺼짐이며 시작 화면에서 켤 수 있다.

## 오류 확인

- 시작 화면에 "운영 자료가 아직 준비되지 않았어요"가 보이면 아래 항목이 그대로 원인이다. 교사용 설정에서 해결한다.
- 화면이 비어 있으면 브라우저 개발자 도구(F12) 콘솔을 확인한다. 시크릿 창은 저장소가 유지되지 않을 수 있다.
- 브라우저 데이터를 지우면 자료를 다시 불러와야 한다. 교사용 설정의 '기본 제공 표지 다시 불러오기'로 복구한다.
