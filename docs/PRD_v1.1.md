## 1. 제품 개요와 목표

책표지 탐정단은 박람회 부스에서 아이가 긴 설명 없이 시작해 책 표지 퍼즐, 틀린그림 찾기, 메모리 게임을 하나의 사건(사라진 이야기 열쇠) 해결로 이어 하고, 마지막에 오늘 만난 책을 다시 보는 체험 웹앱이다. 책 내용 지식이나 독서 능력을 평가하지 않는다.

- 책 표지의 그림을 자세히 관찰하고 비교하는 경험을 준다.
- 한 문장 안내와 제한 없는 도움으로 초등 2~3학년이 끝까지 참여한다.
- 세 활동의 단서로 하나의 사건을 해결하는 성취감을 준다.
- 체험 후 실제 책을 찾아보도록 연결한다.
- 다음 참여자가 같은 기기에서 바로 시작할 수 있도록 운영을 단순하게 한다.
- (v1.1) 나이·숙련도에 맞춰 쉬운 모드와 어려운 모드를 고를 수 있다.
- (v1.1) 운영자가 처음부터 다시 하지 않고 원하는 화면만 바로 점검할 수 있다.

## 2. 범위

| 구현 완료 (v1.1 추가) | 쉬운·어려운 모드 선택, 단계별 여러 판(회차) 진행, 어려운 모드 9조각 퍼즐·12장 메모리, 교사용 점검 모드, 기본 제공 표지 자동 불러오기와 버전 갱신 |
| 미구현 (P1) | 안내 음성, 운영 자료 묶음 내보내기·가져오기, 브라우저 재시작 후 완전한 오프라인 실행 |

참여자마다 문제 도서를 자동으로 바꾸는 기능은 없다. 운영자가 교사용 설정에서 모드별 도서 구성을 정해 둔다.

## 3. 사용자와 이용 상황

기기 한 대에 한 체험 세션을 운영한다. 참가 인원 입력, 팀 배정, 차례 관리는 없다. 한 번의 체험은 선택한 모드의 세 단계를 차례로 마치며 시간제한은 없다.

| 사용자 | 주요 상황 | 제공되는 경험 |
|---|---|---|
| 초등 2~3학년 | 처음 보는 게임을 바로 시작 | 한 문장 안내, 큰 표지, 누르기·끌기 모두 가능한 조작, 쉬운 모드 |
| 유치원생 | 보호자·운영자와 함께 | 그림 중심 안내, 횟수 제한 없는 도와줘 |
| 초등 고학년·중학생 | 같은 부스 체험 | 어려운 모드(퍼즐 3권, 틀린그림 3문제, 메모리 12장 × 2판) |
| 사서교사 | 여러 참여자를 차례로 안내 | 자료 등록, 모드별 도서 구성, 점검 모드, 빠른 초기화, 설정 유지 |

## 4. 이야기와 단서 구조

배경은 책 축제가 열리는 이야기 도서관이다. 장난꾸러기 바람이 축제의 문을 여는 열쇠를 날려 보냈고, 참여자는 책갈피 도우미 ‘모아’와 함께 표지를 살피며 열쇠가 있는 곳을 알아내는 탐정이다. 도입은 세 칸 만화(축제 날 → 열쇠 사라짐 → 표지에 단서)로 보여 주고 ‘바로 출동’으로 건너뛸 수 있다. 최종 행동 버튼은 ‘탐정 출동!’이다.

| 단계 | 이야기 속 임무 | 활동 | 획득 단서 | 완료 대사 |
|---|---|---|---|---|
| 1 조각 작업대 | 조각난 표지 복구 | 표지 퍼즐 | 파란 리본 → ‘파란색’ | 첫 단서야! 열쇠가 있는 곳은 파란색인가 봐. |
| 2 관찰 책상 | 달라진 표지 조사 | 틀린그림 찾기 | 별 모양 쪽지 → ‘별’ | 두 번째 단서는 별이야! |
| 3 기억 책장 | 뒤섞인 책 카드 정리 | 메모리 게임 | 상자 그림 쪽지 → ‘상자’ | 마지막 단서는 상자야! |
| 결말 | 열쇠 위치 발견 | 단서를 합쳐 상자 열기 | 별이 붙은 파란 상자에서 열쇠 | 찾았다! 바람이 열쇠를 이곳으로 날려 보냈구나! |

단서는 단계의 모든 판을 마친 뒤 같은 세션에서 한 번만 지급된다. 단서는 원본 표지 밖의 이야기 연출이며, 게임 성과를 독서 능력이나 지능 평가로 해석하지 않는다.

## 5. 화면 흐름과 이동 규칙

| 화면 ID | 화면 | 주요 요소 | 다음 행동 |
|---|---|---|---|
| S00 | 시작 | 제목, 모아, 쉬운 모드·어려운 모드 버튼, 소리 설정, 교사용 설정 링크 | 모드 버튼 |
| S01 | 사건 소개 | 세 칸 만화, 모아 대사 | ‘탐정 출동!’ 또는 ‘바로 출동’ |
| S02 | 조각 작업대 | 퍼즐(판 수만큼 반복), 완성 표지 미리보기, 도와줘 | 모든 판 완성 |
| S03 | 첫 단서 | 파란 리본, 단서 수첩 | ‘다음 단서 찾기’ |
| S04 | 관찰 책상 | 원본·수정본(문제 수만큼 반복), 찾은 수, 도와줘 | 모든 문제 3곳 발견 |
| S05 | 두 번째 단서 | 별 쪽지, 단서 수첩 | ‘다음 단서 찾기’ |
| S06 | 기억 책장 | 카드 미리보기와 짝 찾기(판 수만큼 반복), 도와줘 | 모든 판 완성 |
| S07 | 마지막 단서 | 상자 쪽지, 단서 세 개 | ‘열쇠 찾으러 가기’ |
| S08 | 사건 해결 | 단서 조합, 파란 상자, 열쇠, 축제, 배지 | ‘오늘 만난 책’ |
| S09 | 오늘 만난 책 | 사용한 원본 표지, 선택적 책 확대 | ‘처음 화면으로’ |
| A00 | 교사용 설정 | 도서·문제 등록, 모드별 도서 선택, 점검 모드, 검증, 저장 | 검증 후 시작 화면 복귀 |

- 게임 화면 상단에 ‘조각 작업대·관찰 책상·기억 책장’을 그림과 글자로 표시한다. 현재 단계는 강조하고 완료 단계에는 도장을 찍는다. 판이 여러 개면 ‘조각 작업대 2/3’처럼 현재 판 수를 함께 표시하고, 모드 이름(쉬운/어려운)을 보여 준다.
- 한 판이 끝나고 다음 판이 남아 있으면 “n/3 완료! 다음 표지 ▶” 안내창이 나온다. 이 안내창은 바깥을 눌러도 닫히지 않고 버튼으로만 진행한다.
- 아직 도달하지 않은 단계는 학생이 직접 열 수 없다. 정답 처리와 단서 지급은 같은 세션에서 한 번만 발생한다.
- 게임 화면 오른쪽 위 ⌂ 버튼은 운영자용 ‘처음으로’이며 확인 창을 거친다.
- 시작 화면 맨 아래 ‘교사용 설정’ 링크(확인 창) 또는 주소 `#admin`으로 교사용 설정에 들어간다.

## 6. 난이도 모드

시작 화면에서 두 모드 중 하나를 고른다. 어려운 모드 자료가 준비되지 않으면 그 버튼만 비활성화되고 사유가 작게 표시된다. 연습 모드(자체 제작 도형 표지)에서는 쉬운 모드만 가능하다.

| 모드 | 1단계 퍼즐 | 2단계 틀린그림 | 3단계 메모리 | 미리보기 |
|---|---|---|---|---|
| 쉬운 모드 | 1권, 2×3 = 6조각 | 1문제, 3곳 | 1판, 4종 × 2장 = 8장(4열) | 3초 |
| 어려운 모드 | 3권, 6조각·6조각·3×3 = 9조각 | 3문제, 각 3곳 | 2판, 각 6종 × 2장 = 12장(6열) | 4초 |

모드 규격은 `js/validate.js`의 `LEVEL_SPEC`에 정의되어 있으며, 모드별 도서 구성은 운영 설정 `levels.easy` / `levels.hard`에 저장된다.

## 7. 게임 규칙

### 7.1 책 표지 퍼즐

| 항목 | 요구사항 |
|---|---|
| 사용 이미지 | 선택한 실제 원본 표지 1장(판마다 다른 책) |
| 구성 | 가로 2 × 세로 3 = 6조각. 어려운 모드 3번째 판은 3 × 3 = 9조각 |
| 기본 입력 | 조각 누르기 → 넣을 자리 누르기 |
| 추가 입력 | 끌어서 배치(마우스·터치 공통) |
| 완료 조건 | 모든 조각이 정답 위치에 고정 |
| 도움 | 선택한 조각의 자리 강조. 선택이 없으면 한 조각과 자리를 함께 강조. 횟수 제한 없음 |

- 전체 표지를 빠짐없이 분할하고 원본 비율을 유지한다. 조각은 회전·뒤집기 없이 섞어 보관함에 둔다(9조각은 5열 배치).
- 정답 위치에서만 붙고 고정된다. 오답 자리는 흔들림 표시와 “다시 살펴볼까?” 안내 후 재시도한다.
- 끌기 실패, 판 밖에 놓기, 터치 취소 후에도 조각이 사라지지 않는다.
- 완료 시 입력을 잠그고 완성 표지를 잠시 보여 준 뒤 다음 판 또는 첫 단서로 이동한다.
- 안내: “조각을 누르고, 알맞은 자리를 눌러요.”

### 7.2 책 표지 틀린그림 찾기

| 항목 | 요구사항 |
|---|---|
| 사용 이미지 | 같은 책의 원본 1장과 수정본 1장(문제마다 다른 책) |
| 차이 수 | 정확히 3곳 |
| 정답 입력 | 두 이미지 중 어느 쪽을 눌러도 인정 |
| 완료 조건 | 서로 다른 정답 3곳 모두 발견 |
| 도움 | 아직 못 찾은 정답 하나의 주변을 2.5초 강조 |

- 원본과 수정본은 하나의 문제(세트) ID로 묶이고, 정답마다 서로 다른 영역 ID를 가진다. 발견하면 양쪽 이미지에 동그라미를 남기고 같은 영역 재입력은 발견 수를 늘리지 않는다.
- 판정은 여백을 제외한 실제 이미지 사각형 기준의 상대 좌표(0~1)로 하며, 손가락 오차를 위해 영역을 1.5% 넓혀 판정하되 한 번에 하나만 인정한다. 화면 크기·회전이 바뀌어도 표시와 판정이 그림을 따라간다.
- 오답은 감점·경고음 없이 “다른 곳도 살펴볼까?”라고 안내한다. 이미지 밖 여백은 오답이 아니라 무시한다.
- 차이 제작 기준: 눈에 띄는 소품의 유무, 분명한 색·모양 변화. 작은 글자나 미세한 농도 차이는 쓰지 않고, 제목·저자명·출판사명은 수정하지 않는다. 세 차이를 모두 색 변화로만 만들지 않는다.
- 원본·수정본·정답 영역 3개·교사 검수 완료를 모두 충족한 세트만 운영에 쓴다. 원본이나 수정본을 바꾸거나 영역을 움직이면 검수 상태가 자동 해제된다.
- 안내: “두 표지에서 다른 곳 3개를 눌러요.”

### 7.3 책 표지 메모리 게임

| 항목 | 요구사항 |
|---|---|
| 사용 이미지 | 서로 다른 실제 원본 표지 4종(쉬운) 또는 6종(어려운) |
| 카드 수 | 책마다 2장씩, 8장·4쌍 또는 12장·6쌍 |
| 최초 미리보기 | 전체 앞면 3초(어려운 모드 4초) 공개 후 시작 |
| 다른 짝 표시 | 1초 후 다시 뒤집기 |
| 도움 미리보기 | 남은 카드 앞면 2초 공개 |
| 완료 조건 | 모든 쌍 발견 |

- 같은 책 ID의 두 카드를 한 쌍으로 판정하며 카드 개별 ID는 서로 다르다. 뒷면은 모두 같고 새 세션마다 위치를 섞는다.
- 미리보기 중 입력 불가, 두 장 비교 중 세 번째 선택 차단, 같은 카드·맞춘 카드 입력 무시. 도움 중에는 일반 입력과 중복 도움을 막고, 한 장만 열린 상태에서 도움을 누르면 선택을 해제한 뒤 공개한다. 도움 종료 후 미완성 카드는 모두 닫힌 상태에서 재개한다.
- 안내: “카드 두 장을 눌러 같은 표지를 찾아요.”

## 8. 결말과 오늘 만난 책

사건 해결 화면은 파란색·별·상자 단서를 함께 보여 주고 모아가 “별이 붙은 파란 상자! 열쇠가 그 안에 있겠어!”라고 말한다. 별이 붙은 파란 상자를 누르면 열쇠가 나타나고 축제의 문이 열리며, 짧은 축하 연출(건너뛰기 가능)과 탐정단 배지, 완료 문구 “사건 해결! 책표지 탐정단, 고마워! 자세히 보고, 비교하고, 기억해서 열쇠를 찾았어!”가 나온다. 상자를 연 시점을 체험 완료로 본다. 여러 상자 중 고르는 추가 문제는 없다.

오늘 만난 책 화면은 이번 세션에서 실제 사용한 책만 책 ID 기준으로 한 번씩(쉬운 모드 6권, 어려운 모드 18권) 원본 표지로 보여 준다. 질문은 “어떤 책이 가장 궁금해?”이며 표지를 누르면 크게 보이고 확인된 제목·저자와 “도서관에서 이 책을 찾아봐!”가 표시된다. 줄거리·등장인물·교육 효과는 쓰지 않는다. 책을 고르지 않아도 ‘처음 화면으로’를 누를 수 있고, 선택은 저장하지 않는다.

### 9.4 이미지 관리

- JPG·PNG·WebP 정지 이미지를 지원하며 가져올 때 디코딩 성공과 실제 크기를 확인한다. 손상·빈 파일은 저장하지 않고 이유를 안내한다.

- 연습용 도형 표지 4종과 연습용 틀린그림은 자동 생성되며 학생 화면에 ‘연습용’을 표시한다. 연습 자료와 실제 자료를 섞어 쓰지 않는다.

점검 모드: 시작 화면의 ‘교사용 점검’ 링크(또는 `#inspect`)에서 모드를 골라 시작 화면부터 점검하거나, 교사용 설정의 점검 버튼(사건 소개, 퍼즐 1·2·3, 첫 단서, 틀린그림 1·2·3, 두 번째 단서, 메모리 1판·2판, 마지막 단서, 사건 해결, 오늘 만난 책)으로 해당 화면을 바로 연다(누르면 현재 변경 내용을 먼저 저장). 빨간 점검 막대에는 현재 화면 이름, 바로 가기 선택, ◀ 이전 / 다음 ▶, ‘이 판 건너뛰기’(현재 판을 완료 처리해 정상 흐름으로 진행), ‘📝 메모’(화면별로 고칠 점을 적고 ‘전체 복사’로 한 번에 복사, 기기에만 저장), ‘점검 종료’(시작 화면), ‘설정으로’(교사용 설정)가 있다. 점검 막대와 메모는 점검 모드에서만 보이며 학생 화면에는 나오지 않는다.

관리자에서 구성을 저장하면 다음 세션부터 적용된다. 교사용 설정은 학생의 주요 행동 버튼과 섞이지 않는다.

## 11. 데이터·저장·실행 조건

| 데이터 | 주요 필드 | 저장 범위 |
|---|---|---|
| Book | id, title, author, authorConfirmed, originalAssetId, isDemo | IndexedDB(기기) |
| ImageAsset | id, blob, width, height, mimeType | IndexedDB |
| DifferenceSet | id, bookId, originalAssetId, modifiedAssetId, regions[3], reviewed, isDemo | IndexedDB |
| Region | id, x, y, width, height (0~1 상대 좌표) | DifferenceSet에 포함 |
| GameConfig | mode(demo/real), soundEnabled, bundleImported, bundleVersion, levels.easy/hard{puzzleBookIds[], differenceSetIds[], memoryRounds[][]} | IndexedDB |
| PlaySession | level, screen, stage, rounds{puzzle,diff,memory}, 퍼즐·틀린그림·메모리 상태, clues, completed, inspect | 현재 세션만 |

- 순수 HTML/CSS/JS, 빌드·외부 패키지·인터넷 없이 `node serve.cjs 8080`(start.cmd)으로 실행한다. 생성형 AI API, 학생 계정, 외부 검색을 쓰지 않는다.
- 처음 열면 `assets/manifest.json`의 표지·틀린그림·기본 구성을 IndexedDB로 가져온다. manifest 버전이 올라가면 기본 틀린그림(수정본·정답 영역)은 자동 교체하고, 교사가 바꾼 모드 구성은 유지한다.
- 새로고침 후에도 등록 자료와 설정은 유지되고 학생 진행은 시작 화면으로 돌아간다. 다른 기기·브라우저로의 동기화는 없다.
- 같은 탭에서는 인터넷이 끊겨도 세 게임과 초기화를 계속 쓸 수 있다. 브라우저를 닫은 뒤의 완전한 오프라인은 P1이다.
- 모든 전환은 세션 상태를 확인하고 실행한다. 예약 동작(미리보기·뒤집기·완료 연출)은 세션 ID를 검사해 초기화 후에는 실행되지 않는다.
- 학생 개인별 로그, 이름, 연락처를 수집하지 않는다. 소리는 기본 꺼짐이며 설정은 기기에 저장된다.
- 화면: 태블릿 가로 1024×768 이상과 노트북을 우선 지원하며 휴대전화 폭에서는 세로 배치와 스크롤을 허용한다. 주요 안내 20px 이상, 주요 버튼 높이 56px 이상.
