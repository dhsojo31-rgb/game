# 책표지 탐정단 교사용 운영 안내

## 1. 부스 시작 전 준비

1. `start.cmd` 실행 → 브라우저에서 `http://localhost:8080` 이 열린다.
2. 시작 화면에 **시작** 버튼이 보이면 운영 자료가 준비된 것이다. 경고가 보이면 3절을 따른다.
3. 시작 화면 맨 아래 **교사용 설정**(또는 주소 뒤에 `#admin`)에서 **체험 전체 미리보기**를 눌러 실제 학생 화면으로 세 단계를 끝까지 해 본다.
4. 확인할 것: 표지 잘림, 틀린그림 정답 위치, 도와줘 버튼, 소리, 처음 화면으로.
5. 시작 화면으로 돌아가 참여자를 받는다.

## 2. 모드와 기본 운영 구성 (제공된 실제 표지)

시작 화면에서 학생이 **쉬운 모드**와 **어려운 모드** 중 하나를 고른다.

| 모드 | 1단계 퍼즐 | 2단계 틀린그림 | 3단계 메모리 | 4단계 숨은그림 |
|---|---|---|---|---|
| 쉬운 모드 | 1권 (6조각) | 1문제 (3곳) | 1판, 4종 × 2장 = 8장 | 1판 (물건 6개) |
| 어려운 모드 | 3권 (6조각·6조각·마지막은 9조각) | 3문제 (각 3곳) | 2판, 각 6종 × 2장 = 12장 | 2판 (8개·6개) |

어려운 모드에서는 한 판이 끝날 때마다 "1/3 완료! 다음 표지 ▶" 안내가 나오고, 단서는 단계의 모든 판을 마친 뒤 한 번만 준다.

| 모드 | 단계 | 사용 도서 |
|---|---|---|
| 쉬운 | 퍼즐 | 낭만 강아지 봉봉 |
| 쉬운 | 틀린그림 | 친구 자판기 |
| 쉬운 | 메모리 | 무지개 목욕탕 · 장군이네 떡집 · 꽝 없는 뽑기 기계 · 하늘 택배 |
| 어려운 | 퍼즐 | 진짜 일 학년 책가방을 지켜라! · 강남 사장님 · 엄마가 유령이 되었어! |
| 어려운 | 틀린그림 | 친구 자판기 · 브로콜리지만 사랑받고 싶어 · 하늘 택배 |
| 어려운 | 메모리 1판 | 무지개 목욕탕 · 장군이네 떡집 · 꽝 없는 뽑기 기계 · 흔한 남매 · 에그박사 · 공포의 편도선 |
| 쉬운 | 숨은그림 | 내 멋대로 친구 뽑기 표지에 숨긴 물건 6개 (별=유리창 스티커, 단추=버튼 줄, 열쇠=동전 투입구 옆, 연필=아래 선반, 삼각자=왼쪽 아래, 컵=위 선반) |
| 어려운 | 숨은그림 | 1판 에그박사 8개(모자=나뭇가지, 선글라스=잠자리채 안, 책=자전거 옆, 별=하늘, 컵=바위 턱, 우산=덩굴, 물고기=폭포, 지우개=풀밭) · 2판 흔한 남매 6개(연필=선반, 가위=바구니, 단추=오리 옆, 열쇠=탁자, 사과=욕조 가장자리, 양말=빗 옆 바닥) |
| 어려운 | 메모리 2판 | 끔찍한 샐러드 · 섬뜩한 코바늘 · 우리 반 회장이 사라졌다 · 몬스터 캠핑장 · 때밀이 장갑 · 고구마랑깨 |

틀린그림 차이:
- 친구 자판기(`cover13_mod.jpg`): ① 왼쪽 위 아이의 빨간 헤드폰이 파란색 ② 오른쪽 아래 노란 새가 없음 ③ 왼쪽 아래 음표가 없음.
- 브로콜리지만 사랑받고 싶어(`cover03_mod.jpg`): ① 오른쪽 위 날아가는 전단지가 없음 ② 가운데 흰 종이가 없음 ③ 브로콜리 몸이 연두색에서 주황색으로.
- 하늘 택배(`cover18_mod.jpg`): ① 오른쪽 시계가 초록색에서 파란색으로 ② 고양이 모자가 분홍색에서 보라색으로 ③ 아빠 상자의 별 스티커가 없음.

도서 정보는 표지에 적힌 글자를 읽어 적었다. 도서 정보(제목·저자)는 운영자가 22권 모두 확인했다.

## 3. 교사용 설정 사용법

- **운영 방식**: '실제 표지로 운영' / '연습 모드'. 연습 모드는 자체 제작 도형 표지를 쓰며 학생 화면에 '연습용'이 표시된다.
- **도서 등록**: 표지 파일(JPG·PNG·WebP) + 제목 + 저자 → 등록. 손상 파일·빈 파일은 저장되지 않고 이유가 표시된다.
- **쉬운 모드 도서 선택**: 퍼즐 1권, 틀린그림 세트 1개, 메모리 서로 다른 4권.
- **어려운 모드 도서 선택**: 퍼즐 3권, 틀린그림 세트 3개, 메모리 1판·2판 각각 서로 다른 6권. 어려운 모드가 덜 준비되어도 쉬운 모드만으로 운영할 수 있다(시작 화면에서 어려운 모드 버튼이 비활성화되고 사유가 작게 표시된다).
- 각 모드 칸 아래 **전체 미리보기** 버튼으로 해당 모드를 학생 화면으로 끝까지 해 볼 수 있다.
- **교사용 점검 모드**: 두 곳에서 들어간다. ① 시작 화면 맨 아래 '교사용 점검' 링크(또는 주소 뒤 `#inspect`)를 누르고 쉬운/어려운 모드를 고르면 시작 화면부터 점검 막대가 붙는다. ② 교사용 설정의 점검 버튼(퍼즐 2, 틀린그림 3, 메모리 2판 등)으로 원하는 화면을 바로 연다(누르면 현재 변경 내용이 먼저 저장된다).
  - 빨간 점검 막대: 현재 화면 이름, '바로 가기' 선택(시작 화면부터 오늘 만난 책까지), ◀ 이전 / 다음 ▶, '이 판 건너뛰기'(현재 판을 완료 처리해 정상 흐름으로 진행), '📝 메모', '점검 종료'(시작 화면), '설정으로'(교사용 설정).
  - 📝 메모: 보고 있는 화면에서 고칠 점을 적으면 "[화면 이름] 내용"으로 쌓인다. 화면을 옮겨도 유지되고(이 기기에만 저장), '전체 복사'로 한 번에 복사해 수정 요청에 붙여넣을 수 있다. '모두 지우기'로 비운다.
  - 점검 막대와 메모는 점검 모드에서만 보이며 학생 화면에는 나오지 않는다.
- **숨은그림 세트 편집(4단계)**: 표지 도서 선택(1·2단계에서 안 쓴 책 권장) → **찾을 물건 추가**를 누르면 물건 그림이 표지 위에 놓임 → 끌어서 숨길 자리로 옮기고 크기·회전 조절 → 오른쪽 표에서 물건 종류 선택(16종) → **미리보기: 직접 눌러보기**로 판정 확인 → **교사 검수 완료** 체크. 물건은 3~10개. ‘표지 속 그림’을 고르면 표지에 원래 있는 그림을 찾게 하고 이름을 직접 적는다.
- **틀린그림 세트 편집**: 원본 도서 선택 → 수정본 이미지 등록(원본과 같은 비율, 차이 정확히 3곳) → **정답 영역 추가**로 3개를 만들고 끌어서 위치·크기 조절 → **미리보기: 직접 눌러보기**로 판정 확인 → **교사 검수 완료** 체크.
  - 원본이나 수정본을 바꾸거나 영역을 움직이면 검수 표시가 자동으로 풀린다. 다시 확인한 뒤 체크한다.
  - 수정본이 없으면 '수정본 준비 필요'로 표시되고 운영에 쓸 수 없다. 원본 두 장으로는 출제되지 않는다.
- **검수 결과 저장**: 모든 변경은 이 버튼을 눌러야 기록된다. 저장 중 오류가 나면 기존 자료가 유지된다.
- **운영 자료 상태**: 부족한 자료, 중복 도서, 영역 오류가 항목별로 나열된다. 모두 해결되어야 시작 화면에 시작 버튼이 나온다.
- **기본 제공 표지 다시 불러오기**: 브라우저 데이터를 지웠거나 실수로 삭제했을 때 `assets/manifest.json`의 표지를 다시 가져온다(이미 있는 책은 건너뜀).

## 4. 현장 운영

- 한 번의 체험 = 퍼즐 → 틀린그림 → 메모리 → 숨은그림 → 사건 해결 → 오늘 만난 책.
- **처음 화면으로**(오늘 만난 책 화면)을 누르면 진행만 초기화되고 자료·설정은 유지된다.
- 중간에 그만둘 때는 오른쪽 위 **⌂** 버튼 → '처음으로'. 확인 창이 있어 학생이 실수로 누르기 어렵다.
- 시간제한, 점수, 이름 입력은 없다. '도와줘'는 단계마다 쉬운 모드 2번, 어려운 모드 3번까지 쓸 수 있다(어려운 모드는 한 단계의 여러 판을 합쳐 셈). 버튼에 남은 횟수가 표시되고 다 쓰면 비활성화된다.
- 소리는 기본 꺼짐. 시작 화면의 소리 버튼으로 켜면 기기에 기억된다.
- 새로고침하면 학생 진행은 처음으로 돌아가지만 자료는 유지된다.

## 5. 주의

- 자료는 **이 기기의 이 브라우저**에만 저장된다. 다른 기기에서는 같은 폴더를 열면 기본 표지가 자동으로 들어오고, 추가 등록한 책은 다시 등록해야 한다.
- 원본 표지 파일은 `assets/covers/`에 있으므로 폴더 전체를 보관한다.
- 시크릿 창에서는 저장이 유지되지 않을 수 있다.
- 실물 책을 부스에 함께 두면 '오늘 만난 책' 화면에서 바로 연결할 수 있다(선택 사항).

## 6. 오프라인 수업용 메모리 카드 인쇄

- 파일: `print/메모리카드_인쇄용_A4.pdf` (바로 인쇄) 또는 `print/memory-cards.html` (서버로 열어 Ctrl+P). 배포 주소에서는 `/print/memory-cards.html` 로 열 수 있다.
- 구성: 표지 22종 × 2장 = 앞면 44장(홀수 쪽 1·3·5·7·9, 마지막 칸 1개 빈칸), 뒷면 공통 디자인(짝수 쪽 2·4·6·8·10, 바로 앞 홀수 쪽의 뒷면). 카드 6×9cm, A4 한 장에 9장, 총 10쪽.
- 인쇄: 용지 A4, 여백 없음, 배율 100%, 배경 그래픽 켜기, 양면 인쇄(긴 쪽 뒤집기)로 뽑으면 앞뒤가 맞는다. 단면 프린터는 홀수 쪽만 먼저 뽑고 종이를 뒤집어 넣은 뒤 짝수 쪽만 인쇄한다. 180g 이상 두꺼운 종이나 코팅을 권한다.
- 점선을 따라 오린다. 저학년은 4~6종(8~12장)만 골라 쓰면 쉽다.

## 7. QR 코드 안내판

- 파일: `print/QR_안내판_A4.pdf` (1쪽 게임 접속 QR, 2쪽 메모리 카드 인쇄 시트 QR), `print/qr.html`(브라우저에서 Ctrl+P), QR 그림만 쓰려면 `print/qr-game.png` / `print/qr-game.svg` / `print/qr-cards.png`.
- 게임 QR은 https://game-five-ochre-48.vercel.app 으로, 카드 QR은 https://game-five-ochre-48.vercel.app/print/memory-cards.html 로 연결된다(둘 다 해독 확인함).
- 부스 안내판·포스터에 붙여 두면 학생이 핸드폰으로 바로 접속할 수 있다. 배포 주소가 바뀌면 QR을 다시 만들어야 한다.
