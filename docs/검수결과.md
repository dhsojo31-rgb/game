## 이후 보완 (같은 날)

- 회차 안내창이 바깥 터치로 닫혀 진행이 멈추던 문제 수정(안내창은 버튼으로만 진행).
- 교사용 점검 모드 추가: 교사용 설정에서 원하는 화면을 바로 열고, 점검 막대로 이전·다음·건너뛰기·종료. 자동 확인 14개 항목 통과.
- 하늘 택배 별 스티커 정답 영역 좌표 수정. 번들 버전 갱신 시 기본 틀린그림이 자동 교체되고 교사의 모드 구성은 유지됨을 확인.
- 어려운 모드 3번째 퍼즐은 9조각(3×3). 디자인은 처음 모습을 유지(사용자 요청).

## 모드별 추가 확인

- 어려운 모드: 퍼즐 3판·틀린그림 3판·메모리 2판이 각각 새 상태로 시작하고, 판 사이에 "n/3 완료! 다음 표지 ▶" 안내가 나온다.
- 상단 단계 표시에 현재 판 수(예: 조각 작업대 1/3)와 모드 이름이 보인다.
- 어려운 모드 자료가 부족하면 시작 화면의 어려운 모드 버튼이 비활성화되고 사유가 작게 표시된다(교사용 설정 검증 목록과 동일).
